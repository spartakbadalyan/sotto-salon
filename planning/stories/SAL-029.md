# SAL-029: Approve supervised paid-pilot readiness

Epic: EPIC-08. Tracking: `planning/roadmap.yaml`.

## Outcome

Produce a concrete release package for a capped one-territory pilot.

## Scope

Approve supervised paid-pilot readiness. Follow `docs/product/mvp.md` and the roadmap dependencies. No service payments, commissions or booking functionality.

## Requirements

- Collect scoped legal/provider decisions, staffing/support/refund readiness, recovery and security evidence.
- Set proposed 25-advertiser cap, capacity/stop thresholds and rollback before launch.
- Rehearse full journeys and failure cases with authorized test identities; require named operator go/no-go separately from story completion.

## Data and API

Readiness links immutable build, territory, policy/provider versions, owners and non-sensitive evidence references.

## Failure and Security

Unmet mandatory decisions, staffing or security gates block real onboarding and payments.

## Acceptance Criteria

- SAL-029-AC01: Every P0 prerequisite and pilot decision has traceable accepted evidence.
- SAL-029-AC02: Publication/cancel/withdrawal/report/appeal/urgent rehearsal succeeds.
- SAL-029-AC03: Rollback, country shutdown and capacity limits are demonstrated.
- SAL-029-AC04: Accountable operator records go/no-go with build, territory and conditions.

## Verification

- Acceptance walkthrough for SAL-029 with recorded results
- Named specialist review and evidence references; record any no-go outcome
